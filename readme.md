# Retinal OCT Classification using Deep Learning

## Overview

This project focuses on classifying retinal OCT images into four categories:

* CNV
* DME
* DRUSEN
* NORMAL

Three models were implemented and compared:

* CNN (baseline) 
* EfficientNet-B0
* Resnet50
* MobileNetV2

## Results Summary

| Model                 | Test Accuracy |
| --------------------- | ------------- |
| CNN                   | ~98.45%       |
| EfficientNet-B0       | ~81.92%       |
| ResNet50              | ~85.85%       |
| MobileNetV2           | ~80.68%       |
