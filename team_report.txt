─────────────────────────────────────────
HOW CHALLENGES WERE HANDLED IN THE CODE
─────────────────────────────────────────

Challenge 1 — Dataset Imbalance (CNV ~37k vs DRUSEN ~8k):
  Fix → Weighted Cross-Entropy Loss using class_weight parameter in .fit()
  The weights are auto-computed from your actual folder counts so they
  always adapt to whichever dataset split you use.

Challenge 2 — Noisy/Speckle Images:
  Fix → Gaussian noise injection in the training augmentation pipeline
  (preprocessing_function=add_gaussian_noise). This forces the model to
  learn features that are robust to OCT speckle noise, not reliant on it.

Challenge 3 — Overfitting:
  Fix → Three layers of defence:
    (a) Heavy data augmentation (rotation, shift, zoom, flip, brightness)
    (b) Dropout (0.25 → 0.5 progressively through the network)
    (c) L2 kernel regularisation on every Dense and Conv layer
    (d) EarlyStopping + ReduceLROnPlateau callbacks

Challenge 4 — Inter-Class Similarity (e.g. DME vs CNV fluid pockets):
  Fix → Grad-CAM heatmaps in all three notebooks. These visualise exactly
  which retinal region each model is focusing on, showing whether it's
  learning clinically meaningful features or just background texture.

SETUP / HOW TO RUN
─────────────────────────────────────────

1. Place the Kermany 2018 dataset in the same folder as the notebooks:
     ./OCT2017/train/  (CNV, DME, DRUSEN, NORMAL subfolders)
     ./OCT2017/val/
     ./OCT2017/test/

2. Install dependencies:
     pip install tensorflow scikit-learn matplotlib seaborn opencv-python pandas

3. Run notebooks in order: 01 → 02 → 03
   The last cell of notebook 03 has a comparison table — fill in your
   results from all three runs and save it as model_comparison_table.csv

─────────────────────────────────────────
DATA SPLIT
─────────────────────────────────────────
The official Kermany test set has been kept completely untouched throughout
all training. The 80/20 train-val split is handled by the dataset's
pre-existing folder structure. If your local copy does not have a val/
folder, merge train and val and add:

  validation_split=0.2  in ImageDataGenerator
  subset='training' / subset='validation' in flow_from_directory
